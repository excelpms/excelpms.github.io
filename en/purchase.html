Before you purchase

Licensing & usage information

Device-bound licensing
Registration codes are issued for authorized devices. Copying a workbook or registration code to another computer does not automatically enable Full mode. Workbook and local licensing must also match and pass validation.
Free version upgrades
PMS purchases include free access to subsequent version upgrades.
Sharing project information
Use Viewer or VDR Only to share project views, or export reports. Recipients who need full management functions require matching valid authorization.
Software license
PMS is proprietary software. Purchase grants the applicable right to use the software and does not transfer copyright. Users can configure project rules, working calendars and report content within the supported scope.
Requirements & interface language
Use Microsoft Excel 2013 or later for Windows desktop with macros enabled. The PMS workbook is currently in English; switching the website language does not change the workbook language.
